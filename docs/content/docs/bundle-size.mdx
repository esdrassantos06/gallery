Measured with [size-limit](https://github.com/ai/size-limit) through `npm run size`, on version 1.0.0, minified and compressed with brotli. React and React DOM are excluded, since they are peer dependencies.

| Entry                          | Size    |
| ------------------------------ | ------- |
| `import { Lightbox }`          | 9.39 kB |
| Everything the package exports | 9.8 kB  |
| `styles.css`                   | 2.25 kB |

There are no runtime dependencies, so these numbers are the whole cost.

## Measure it yourself

```bash
npm run build
```

```bash
npm run size
```

The entries are defined in `.size-limit.json`, and CI runs the same check on every pull request, right after the build.

## Keeping it small

- The package is ESM only and marks only CSS as a side effect, so bundlers can drop the hook and helpers you do not import.
- Zoom, slideshow, rotation and download are part of the main component, so turning them off with props does not make the bundle smaller. The numbers above already include them.
- Load the lightbox lazily if it is not needed for first paint:

```tsx
const Lightbox = lazy(() =>
  import("@esdrassantos06/gallery").then((m) => ({ default: m.Lightbox })),
);
```

Keep it inside `Suspense`, and note that the first open waits for the chunk.
