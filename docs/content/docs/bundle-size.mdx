Measured with [size-limit](https://github.com/ai/size-limit) through `npm run size` every time this site is built, minified and compressed with brotli. React and React DOM are excluded, since they are peer dependencies.

<BundleSize />

The grids and the filter are tree-shaken away when you only import `Lightbox`.

There are no runtime dependencies, so these numbers are the whole cost.

## Measure it yourself

```bash
npm run build
```

```bash
npm run size
```

The entries are defined in `.size-limit.json`, and CI runs the same check on every pull request, right after the build.

## Keeping it small

- The package is ESM only and marks only CSS as a side effect, so bundlers can drop the hook and helpers you do not import.
- Zoom, slideshow, rotation, flip, share, download, the overflow menu, idle controls and pager dots are part of the main component, so turning them off with props does not make the bundle smaller. The lightbox number above already includes them.
- Load the lightbox lazily if it is not needed for first paint:

```tsx
const Lightbox = lazy(() => import("liftbox").then((m) => ({ default: m.Lightbox })));
```

Keep it inside `Suspense`, and note that the first open waits for the chunk.
