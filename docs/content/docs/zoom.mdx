Built-in images can be magnified up to `maxScale` times their fitted size. Zoom is on by default.

<Demo count={4} zoom={{ maxScale: 4 }} />

| Input                       | Action                                                  |
| --------------------------- | ------------------------------------------------------- |
| Mouse wheel, trackpad pinch | Zoom around the pointer                                 |
| Double click, double tap    | Zoom to `doubleTapScale` at that point, or back to 1    |
| Two-finger pinch            | Zoom around the fingers. Moving them pans.              |
| Drag while zoomed           | Pan, stopping where the image edge meets the stage edge |
| Zoom in and out buttons     | Multiply or divide by `step`. Disabled at the limits.   |
| `+`, `-`, `0`               | Same as the buttons. `0` resets.                        |

## Options

```tsx
<Lightbox zoom={{ maxScale: 4, step: 2, doubleTapScale: 2.5, wheel: false }} {...props} />
```

## Behavior

- Zoom resets when the slide changes, the window resizes or the viewer closes.
- While zoomed, `sizes` grows to the magnified width, so the browser can switch to a sharper `srcSet` candidate.
- Pinching past the limits meets resistance and settles back on release.
- The root gets `data-zoomed` while the image is magnified, and `.eg-zoom` gets `data-gesture` while a pinch, pan or wheel zoom follows the pointer.
- Slides drawn by `render.slide`, videos and embeds do not zoom. The zoom buttons are hidden on them.

`zoom={false}` turns all of it off.
