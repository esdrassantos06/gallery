title: Styling
description: Restyle the lightbox with --eg-* CSS variables.
---

The lightbox is neutral by default: a black backdrop, the counter top left, the toolbar top right and the caption at the bottom. Restyle it with CSS variables on `.eg-root`, on any ancestor, or through `style`.

```css
.eg-root {
  --eg-background: #101418;
  --eg-color: #f3efe6;
  --eg-color-muted: rgb(243 239 230 / 0.7);
  --eg-focus-color: #f2b544;
  --eg-arrow-background: rgb(242 181 68 / 0.16);
  --eg-radius: 999px;
  --eg-duration: 480ms;
}
```

```tsx
<Lightbox style={{ "--eg-background": "#101418" } as React.CSSProperties} {...props} />
```

The demo below uses exactly the variables above, and nothing else.

To add your own classes to any part instead, use `classNames`. See [Class names and data attributes](/docs/class-names).

## Light theme

```css
.eg-root {
  --eg-background: #f6f5f2;
  --eg-color: #0b0b0c;
  --eg-color-muted: rgb(11 11 12 / 0.64);
  --eg-focus-color: #0b0b0c;
  --eg-arrow-background: rgb(255 255 255 / 0.7);
  --eg-caption-background: none;
  --eg-selection-background: rgb(11 11 12 / 0.16);
}
```

## Tailwind CSS

The stylesheet has no Tailwind dependency and works next to it. Set variables with arbitrary properties on `className`:

```tsx
<Lightbox className="[--eg-background:var(--color-zinc-950)] [--eg-radius:9999px]" {...props} />
```
