`react` and `react-dom` 18 or 19 are peer dependencies. Nothing else gets installed.

## Stylesheet

Import the CSS once, anywhere in your app. A root layout or your entry file is a good place.

```ts
import "liftbox/styles.css";
```

The package marks CSS files as side effects, so bundlers keep the import. Without it the lightbox still works, but it has no layout.

## Exports

import {
