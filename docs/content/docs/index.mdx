`liftbox` is a lightbox for React. Give it a list of slides and an index, and it opens the image out of the thumbnail that was clicked, lets people swipe, zoom and read captions, then flies back when they close it.

<Demo count={6} />

## What you get

- An open and close animation that starts and ends on your thumbnail, with a fade and zoom fallback when there is none.
- Arrows, keyboard, swipe and flick navigation, with `slide`, `fade` and `zoom` transitions.
- A thumbnail strip, zoom with every input people expect, fullscreen, rotation and downloads.
- Native video with captions, YouTube and Vimeo embeds without their player scripts, and any page in an iframe.
- A slideshow that pauses when the user takes over.
- Fast with thousands of images and videos. See [Performance](/docs/performance).
- [Flip](/docs/flip), [share](/docs/share), [pager dots](/docs/pager), [idle controls](/docs/idle), [right-to-left](/docs/rtl) and an [overflow menu](/docs/toolbar) that keeps a full toolbar usable on a phone.
- Deep links through the URL hash, closed by the back button.
- Modal dialog semantics, a focus trap, focus return, a live region and a scroll lock that keeps the page still.
- Zero runtime dependencies. React is a peer dependency.
- Optional [justified, masonry and uniform grids](/docs/grids) and a [category filter](/docs/filter).

## Bring your own grid

The lightbox does not need the built-in grids. Use your own markup, a CSS grid, a masonry library or CMS output, and point the lightbox at it with `getThumbnail`.

## Compatibility

|               | Supported                                                                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| React         | 18 and 19, as a peer dependency                                                                                                                              |
| Module format | ESM only, with TypeScript declarations                                                                                                                       |
| Frameworks    | Any React setup, including the Next.js App Router                                                                                                            |
| Browsers      | Current evergreen browsers. Without `ResizeObserver` or the Web Animations API it falls back to window resize events and opens without the flight animation. |
