## Required props

`slides`, `open` and `onClose`. Everything else has a default.

## Controlled state

`open` and `index` are yours. The lightbox calls `onIndexChange` and `onClose` when the user wants to change them, and you pass the new values back. Changing `index` while open moves to that slide with the current transition.

## Grouped options

Some props take either `true` or an options object:

| `video`     | `{ autoplay }`, see [Slides](/docs/slides#autoplay) |
