## Why choose this package

It is MIT, so you can ship it in a closed-source product without buying anything or setting a license key. That is the real difference from lightGallery 3, which covers a lot of the same ground (grids, deep links, YouTube and Vimeo) but asks for GPL-3.0 or a paid license. [Migrating from lightGallery](/docs/migration-lightgallery) maps the props.

Zoom, thumbnails, video, YouTube, Vimeo, slideshow, fullscreen, download, share, rotation and deep links are all props on one component. In YARL each of those is a plugin with its own import, and grids come from a second package, react-photo-album.

The image opens out of the thumbnail you clicked, cropped the same way, and flies back into it when you close. PhotoSwipe, lightGallery and react-photo-view do this as well; YARL does not.

Masonry, justified and uniform grids and a category filter ship in the same package, and bundlers drop them when you only import `Lightbox`. No runtime dependencies either, and it stays fast with [thousands of slides](/docs/performance).

## When to pick another library

- **YARL** if you need React 16 or 17, an inline carousel, or the smallest possible core with only the plugins you use. It also has the largest community of the React options here.
- **PhotoSwipe** if you are not on React, or want the same lightbox across frameworks.
- **lightGallery** if you need Wistia, comments or a vendor-supported license, and the GPL-3.0 or commercial license works for you.
- **react-image-gallery** if you want a carousel on the page rather than an overlay.
- **react-photo-view** if you only need a minimal image viewer and no video or thumbnails. Its last release was in January 2025.

This package has no inline mode, and its built-in features cannot be dropped from the bundle one by one. The 13.12 kB above always includes all of them. See [Bundle size](/docs/bundle-size).

## How the sizes were measured

With [size-limit](https://github.com/ai/size-limit) and `@size-limit/preset-small-lib`, minified and compressed with brotli, React and React DOM excluded. JavaScript only, without stylesheets. Each entry imports:

| Library             | Imports                                                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| liftbox             | `Lightbox`                                                                                                                  |
| YARL                | The default export, then also Zoom, Thumbnails, Fullscreen, Slideshow, Video, Captions, Counter, Download, Share and Rotate |
| PhotoSwipe          | `Gallery` and `Item` from react-photoswipe-gallery, and `photoswipe`                                                        |
| lightGallery        | `@lightgallery/react` with its zoom, thumbnail, video, fullscreen and autoplay plugins                                      |
| react-image-gallery | The default export                                                                                                          |
| react-photo-view    | `PhotoProvider` and `PhotoView`                                                                                             |

Moving over? See [Migrating from yet-another-react-lightbox](/docs/migration) and [Migrating from lightGallery](/docs/migration-lightgallery).
